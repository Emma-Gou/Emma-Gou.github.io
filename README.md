Personal teaching portfolio for Kunyang (Emma) Gou.

## Publishing updates
This repository is intended for GitHub Pages. The site entry point is `index.html`.
Custom visual refinements are in `assets/css/custom.css`, which is loaded after the original theme stylesheet.

## Privacy note
The public Georgia educator-certificate PDFs have intentionally been removed from this repository because the official documents display personal address and certificate-number information. The website lists the credential and validity period; official documentation can be shared privately with prospective employers.

The current CV download remains at `images/Kunyang(Emma) Gou - CV.pdf`.
